Código-fonte / Pré-formatação

Tag para linhas de comando é <code>:
O comando document.getElementById('teste') é escrito em linguagem JavaScript.

Tag para pré-formatação é <pre> (define exatamente como no código-fonte, mantendo espaços em branco, tabulações e quebras de linha): 

            
    num = int(input('Digite um número'))
    if num % 2 == 0:
        print(f'O número {num} é PAR')
    else:
        print(f'O número {num} é ÍMPAR')
    print('Fim do programa')

Citações simples

Tag para citações simples é <q>:
Como diria o pai de um amigo: o computador é um burro muito rápido

Citações completas

Tag para citações completas é <blockquote>:
Segundo Jeff Noble, no seu livro HTML para Leigos:

A diferença entre elementos inline e um bloco de texto é importante. Os elementos HTML neste capítulo descrevem os blocos de texto.

Abreviações

Tag para abreviações é <abbr>:
Estou estudando HTML e CSS. Estou adorando!

Texto invertido

Tag para texto invertido é <bdo> (bidirectional override):
Estou aprendendo a criar coisas em HTML.
